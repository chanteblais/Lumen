- **2026-09-12 · Voice works everywhere without a vendor.** Brave exposes `SpeechRecognition` but ships neither Google's speech-service keys nor the on-device speech component, so recognition can never succeed there; Firefox has no API at all. Rather than a paid transcription API (new vendor, key, audio leaving the device; Claude itself takes no audio), the fallback is Whisper in the browser: `@huggingface/transformers` running `whisper-base.en` on WebGPU in a worker, behind the same `useVoiceInput()` surface (`components/chat/voice/`). Costs a one-time ~90 MB model download per browser; buys privacy and zero marginal cost. Engine choice is automatic and invisible.
