## Conceptual lineage and dispositions

| Earlier approach | Reason for change or precision | Current disposition |
|---|---|---|
| Task initiation as the centre | Foundations and full space docs encompass direction, context, reflection and return | Initiation remains essential within an active-life model that helps the user hold less. |
| Required sorting rejected | Optional correction expresses judgment rather than maintenance | Manual correction is supported; explicit authority and temporal scope constrain learning. |
| A single priority / Later shorthand | Importance, urgency, user order and current attention differ | Use the [shared vocabulary](../product/shared-model.md); Not today is a scoped exclusion, not a tomorrow schedule. |
| Library framed as where have I been | Active Threads, commitments and current context exceed history | Broad Library; historical and intellectual exploration are parts of its role. Spatial IA is a design proposal, not the ontology. |
| Book-only visuals and avatar-only Lumi | Inhabited places were explicitly adopted | Visual Language replaces the old prohibition; legibility, editorial restraint and production lessons survive. |
| Earning/spending coherence | Conflicts with continuity-based growth and creates a reward economy | Superseded by approved continuity-based growth. Preserve recognition without points, unlocks or maintenance. |
| Action or completion as the default outcome | Reflection, restored context and leaving the app can be useful | Home and Study allow richer outcomes; no new compulsory reporting. |
| Partial Spaces / Garden received in repo | Complete sources supplied; Garden is revised, not just gap-filled | Full source sections integrated; earlier text archived; section crosswalk below. |

## Implementation gaps to keep visible

- One capped context block is not full space-specific retrieval or Study compression.
- Current intentions combine conceptual Intention and Action; commitments, relationships and Threads are not all first-class structures.
- Existing source labels do not fully implement explicit / observation / inference / derived provenance.
- Temporary exclusions, durable priority and rest at multiple timescales are not yet fully represented.
- The session sweep and strategy reflection can overinterpret abandonment; a timeout alone does not establish failure (open question 28).
- Stable plans already protect orientation; adaptive triggers and explanation design remain open (26).
- Search, export, retention, archival, richer outcomes and mobile presence are not implied to be built by their inclusion in product direction.
