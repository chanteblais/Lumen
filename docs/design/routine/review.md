Tools are `hold_priority` and `let_go_priority`. The planner treats a priority as a lean, and something time-sensitive today still goes first.

- **The Library is not only a room in code:** `/library/table` ("On the table"), books and Library sections exist behind debug mode. Users still see only the room.

Refreshing the package (`docs/context-package.md` → Refresh) would stop new proposals revisiting settled or removed ground. It writes to Google Drive, so it waits for Chanté's go-ahead.
