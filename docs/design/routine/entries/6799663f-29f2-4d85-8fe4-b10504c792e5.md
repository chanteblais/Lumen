### CURRENT CANON

Focus Together already exists on Home: one session at a time, with a goal, first step, planned duration, elapsed-time bar, and periodic check-ins such as **Yep**, **Stuck**, **Got distracted**, and **Done**. The current implementation can also sweep a session that remains open far beyond its planned duration into an “abandoned” state, and that abandonment can negatively affect what Coherence learns about the strategy. fileciteturn4file0L2-L2

That conflicts with a settled principle: **inactivity does not prove avoidance, low capacity, or failure**. Coherence is supposed to help people leave the app to act, reflect, or rest; disappearing from the interface can itself be a perfectly good outcome. fileciteturn5file0L2-L2

### OPEN QUESTION

Q28 asks what a session ending can actually tell us. The docs specifically distinguish **unknown ending**, **explicit abandonment**, and **useful work outside the app**, while warning that richer outcomes must not create another reporting obligation. fileciteturn7file0L2-L2

### PROPOSAL — **Silence is not an outcome**

I’d separate two things that the current implementation is partly conflating:

**Did the session stop being active in the interface?**

and

**What happened to the work?**

The first can be known mechanically. The second often cannot.

So when a Focus Together session goes quiet, Coherence should close the *interface state* without assigning a *meaning state*.

Internally, I’d give session endings something like:

**Known positive** — user explicitly says Done, or later confirms they kept going.  
**Known difficulty** — user explicitly says Stuck, abandoned it, or reports that the strategy was unhelpful.  
**Changed course** — user intentionally switched to something else.  
**Unknown** — the conversation simply stopped.

And **Unknown should be the default when evidence runs out**.

That means a session could disappear from the active UI after its timeout while remaining semantically:

> *No recorded ending.*

Not “failed.” Not “abandoned.” Just unknown.

The important consequence is in learning. **Unknown sessions should contribute zero evidence about whether the strategy worked.** If the user chose “body double,” disappeared for two hours, then returned tomorrow, Coherence should not quietly learn that body doubling is ineffective.

Later evidence can resolve the ambiguity without requiring a retrospective form. If the user says:

> “I actually got the whole paper done last night,”

Lumi can connect that back to the open session as **continued outside Coherence**.

If the intention is later marked done, that is useful observational evidence that progress occurred, but not necessarily proof that *the session strategy caused it*. Coherence can preserve that distinction rather than turning correlation into confidence.

There is still room for a very occasional lightweight reconciliation. If the previous session is genuinely relevant when the user returns, Lumi might say:

> “Last time we were working on the practicum notes. Did you end up staying with them, or did the day go somewhere else?”

But this should be **context recovery**, not required session bookkeeping. “Doesn’t matter” or simply continuing the conversation should leave the ending unknown.

I’d also change the language around stopping. Instead of an implicit success/failure dichotomy, session-end actions could carry meanings such as:

**Done for now**  
**I got stuck**  
**I switched gears**  
**I’m stopping here**

Each says something materially different, and none needs to be framed as failure.

This gives Coherence a cleaner learning rule:

**Only learn evaluatively from evidence the user actually supplied.**

Observed behaviour can inform context, but it should not acquire a psychological interpretation merely because the app lost sight of the person.

I wouldn’t mock this up yet. The visible UI change could ultimately be tiny; the important improvement is semantic. It prevents Coherence from making one of the easiest—and most damaging—productivity-app mistakes: treating **absence from the system as evidence that life went badly outside it**.
