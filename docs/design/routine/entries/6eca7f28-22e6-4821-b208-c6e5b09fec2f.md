## DIRECTION

I think Insights should eventually stop being understood as a **place**.

“Insight” is really a relationship between Coherence and information that originated somewhere else:

> Lumi noticed something that may matter, but you have not yet said that it does.

That is qualitatively different from an Intention, Today item, or commitment. Preserving that uncertainty is valuable.

The strongest future architecture would therefore treat these items as **unconfirmed context** that can be encountered from the place where broader life context lives, rather than giving this particular input source permanent top-level navigation.

## OPEN QUESTION

This is **Q4 — Where does Insights belong?** The current separate mail-lead page is implemented, but its eventual placement is explicitly unsettled; the open question calls for a projection through Library, Home, or elsewhere without creating inbox-processing work or flooding Today. fileciteturn13file0L9-L9

The interesting part is not just where to move the existing page.

It is:

> **Where should Coherence put things it has noticed before the user has decided whether they belong in their life model?**

## PROPOSAL — **Insights becomes “Noticed,” a temporary Library lens rather than a permanent destination**

I would eventually remove **Insights** from the primary navigation and let Library contain a lightweight **Noticed** lens.

“Noticed” describes the epistemic state better than “Insights.” It does not claim importance, actionability, or even correctness. It simply means:

> Lumi encountered something outside your current model that might deserve your attention.

That lens could contain the same kind of Gmail-derived leads the existing Insights page already surfaces, but its semantics would broaden naturally later to other sources if Coherence gains them: calendar changes, messages, imported documents, or other connected context.

Crucially, **Noticed is not another inbox**.

It should not have unread counts, red dots, “12 new things,” or an expectation that the user regularly clears it. The current no-badge navigation language is worth preserving here.

A noticed item remains lightweight until one of three things happens:

1. **The user confirms it matters.**  
   “Still needs doing” can promote it into the shared model as an Intention or another appropriate structure.

2. **The user dismisses it.**  
   “Let it go” resolves it without creating work.

3. **It loses relevance.**  
   Coherence can eventually stop foregrounding it while retaining whatever provenance policy is settled under Q25.

The important conceptual boundary is:

> **Detection does not equal adoption.**

That is already implicit in the current Insights implementation. I would make it an explicit product rule.

### Library is the right parent because it represents breadth

Today answers:

> What deserves attention now?

Home answers:

> What is going on?

Library is becoming:

> What exists in the wider shape of my life?

A tentative external lead belongs closest to that third question.

It is something Coherence knows *about*, but it has not yet been granted foreground status.

This also prevents a common failure mode in AI productivity products: every piece of extracted information immediately becoming a task. A message saying “Maybe we should get coffee next month” should not silently join a backlog simply because a model can parse an action from it.

### Home can reference Noticed context without becoming its storage location

If the user is already talking about something relevant, Lumi should absolutely be able to bring a noticed item into the conversation:

> “There was also an email from Esther about office access that may relate to this.”

But that is **contextual retrieval**, not moving Insights into Home.

Home remains conversational and selective. The Noticed lens remains where the user can deliberately inspect the broader pool.

Likewise, Today should only receive a lead after there is enough authority to treat it as part of the user’s commitments or current attention.

That gives a clean progression:

**External signal → Noticed → user/context confirms significance → shared life model → possibly Today**

Not every item has to travel the whole path.

### I would make the Library entry quiet and non-demanding

I would not put a large **NOTICED: 7** panel in the middle of the room.

Given the actual current Library composition, the future access point should feel like one optional way into the breadth of the room—not the purpose of the room.

This could eventually be represented through one of the Library’s broader navigation mechanisms once Q3 is settled. I would intentionally **not** decide here whether that is a plaque, reading table, collection slot, Lumi interaction, or another mechanism, because doing so would accidentally resolve the still-open Library navigation problem.

The information architecture can be settled before the spatial gesture:

> Library owns access to tentative externally noticed context.  
> The exact Library interaction remains Q3 territory.

That separation is useful.

### This also gives “Insights” a better long-term meaning

I’m not sure the word **Insights** should survive as the name of a destination.

There may eventually be genuinely derived insights in Coherence:

> “Your hardest starts tend to happen after unscheduled mornings.”

That is a very different epistemic object from:

> “An email appears to contain something you may need to do.”

Calling both *Insights* muddies the model.

I would reserve **insight** for actual synthesis or interpretation if Coherence ever formalizes that concept.

**Noticed** is appropriately modest for extracted external leads.

## HISTORICAL / REJECTED BOUNDARY

I would not turn Library into a unified inbox for email, calendar, messages, documents, and tasks. That would reproduce the maintenance burden Coherence is trying to remove.

I would also not automatically promote externally inferred actions into Today. Today’s omission only works if appearing there carries meaningful confidence.

And I would not add badges to the Library or navigation to signal that unreviewed observations are piling up. That creates a new debt counter even if the colour is gentle.

The principle I would add to the emerging canon is:

> **Coherence may notice more than the user has adopted. Keep that boundary visible. Unconfirmed external context belongs in the breadth of Library; it enters Today only after it becomes meaningfully part of the user’s life model.**
