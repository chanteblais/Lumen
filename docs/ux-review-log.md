# UX Review Log

Running log of findings from UX passes. Each finding carries a **Severity** (how much it hurts someone using Rali — with the EF lens: does it add burden?), an **Effort** guess, and a **Status** (`proposed` → Chanté decides → `fix agreed` / `fixed` / `dismissed`). Newest review at the top. Fixes are only applied once agreed.

Finding format: `### N. <title> · Severity: … · Effort: … · Status: …` followed by a short paragraph and the suggested fix.
